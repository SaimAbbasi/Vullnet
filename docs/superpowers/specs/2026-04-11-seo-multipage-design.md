# SEO & Multi-Page Architecture — Design Spec
**Date:** 2026-04-11
**Project:** Vullnet Nura Group website
**Repo:** https://github.com/SaimAbbasi/Vullnet

---

## Goal

Convert the current single-file `index.html` into a properly structured multi-page static site using Eleventy (11ty), with full SEO metadata per page and auto-deploy via Vercel on GitHub push.

---

## Architecture

### Build Tool
**Eleventy (11ty)** — static site generator. Reads from `src/`, outputs to `_site/`. No client-side JS framework. Output is pure static HTML.

### File Structure

```
VullnetRepo/
├── src/
│   ├── _includes/
│   │   ├── base.njk          # Base layout: <head>, nav, footer
│   │   ├── nav.njk           # Navigation component
│   │   └── footer.njk        # Footer component
│   ├── _data/
│   │   └── site.js           # Site-wide SEO defaults (name, baseUrl, defaultDescription)
│   ├── index.njk             # Home — hero section      → /
│   ├── about.njk             # About section            → /about
│   ├── services.njk          # Services section         → /services
│   ├── values.njk            # Values section           → /values
│   ├── process.njk           # Process section          → /process
│   └── contact.njk           # Contact section          → /contact
├── public/                   # Static assets (pass-through copy)
├── .eleventy.js              # Eleventy config
├── package.json
└── vercel.json               # Vercel build config
```

### Output (what Vercel serves)

```
_site/
├── index.html                # /
├── about/index.html          # /about
├── services/index.html       # /services
├── values/index.html         # /values
├── process/index.html        # /process
├── contact/index.html        # /contact
├── sitemap.xml               # auto-generated
└── robots.txt                # points crawlers to sitemap
```

## SEO Implementation

### Per-Page Front Matter
Each `.njk` page file has a front matter block:

```yaml
---
title: "Services | Vullnet Nura Group"
description: "Commercial interior execution across Ontario — demolition, millwork, walls & ceilings, finishing, and trade coordination."
permalink: /services/
---
```

### Tags Generated Per Page (in `base.njk`)
- `<title>` — from front matter `title`
- `<meta name="description">` — from front matter `description`
- `<link rel="canonical">` — from front matter `permalink` + site base URL
- Open Graph: `og:title`, `og:description`, `og:url`, `og:type`, `og:site_name`
- Twitter Card: `twitter:card`, `twitter:title`, `twitter:description`
- `<meta name="robots" content="index, follow">`

### JSON-LD Structured Data
`LocalBusiness` schema on every page:

```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Vullnet Nura Group",
  "description": "High-performance commercial interior execution across Ontario.",
  "url": "https://vullnet.vercel.app",
  "address": {
    "@type": "PostalAddress",
    "addressRegion": "ON",
    "addressCountry": "CA"
  }
}
```

### sitemap.xml
Auto-generated by Eleventy plugin (`@11ty/eleventy-plugin-rss` or custom template). Lists all 6 pages with `<lastmod>` set to build date.

### robots.txt
```
User-agent: *
Allow: /
Sitemap: https://vullnet.vercel.app/sitemap.xml
```

## Build & Deploy

### Scripts (package.json)
```json
{
  "scripts": {
    "dev": "eleventy --serve",
    "build": "eleventy"
  }
}
```

### vercel.json
```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "_site",
  "installCommand": "npm install"
}
```

### Deploy Flow
1. Push to `main` on GitHub
2. Vercel detects push, runs `npm install && npm run build`
3. Serves `_site/` — clean URLs work natively (`/about` not `/about.html`)
